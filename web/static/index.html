文章 .txt 格式与自动插图说明
1. 标题与文件名规则 默认取 .txt 文件第 1 行作为文章标题，其余行作为正文；若文件只有 1 行或首行为空，则自动使用文件名（去除 .txt 后缀）作为文章标题。
2. 自动分段与 HTML 排版 自动去除 UTF-8 BOM 与多余空行，将正文纯文本行自动整理为标准 <p> 段落格式后推送至 AnqiCMS 导入接口。
3. 自动关键词提取与关键词分栏目 自动提取文章核心关键词写入标签/摘要字段；若站点配置了「标题关键词自动分栏目」，会按最长命中关键词优先匹配目标栏目 ID，未命中则归入默认栏目 fid。
4. 绑定图库自动插图 在站点设置绑定图库后，发布时将从该图库随机抽取一组图片 URL 自动穿插到文章段落中；无需在 .txt 中手写图片 HTML，选择「不自动插图」则纯文本发布。
