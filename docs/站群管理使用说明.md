# AnqiCMS 站群管理工具 — 站群管理使用说明

本指南面向站点管理员，介绍如何配置站群参数，以及如何使用**友链中心（单站友链、统一上下链、站群互链）**、**一键跳转后台**与**统一版本检测/分批在线升级**功能。

---

## 一、站点配置与 AnqiCMS 后台准备

### 1.1 在工具中配置站群与后台信息

你可以在**「配置中心」**选中任意站点，底部**「站群与后台」**区域填写以下信息（也可在「新建站点」对话框的「站群信息（可选）」中直接填写）：

| 配置项 | 是否必填 | 说明 |
| :--- | :--- | :--- |
| **站点显示名** | 选填 | 站群互链时作为指向该站的**默认友链锚文本（标题）**；留空则默认使用「站点名称」。 |
| **站点分组** | 选填 | 如 `主站`、`行业站A`、`资讯池`（最长 64 字符）。配置后可在友链中心和升级中心按分组一键筛选站点。 |
| **MCP Token** | 推荐填写 | 用于 MCP 协议通信（版本检测、在线升级、MCP 工具探测等）。**若留空，工具会自动尝试从「发布接口地址（jiekou）」中的 `?token=...` 提取导入 Token 作为回退**。 |
| **后台路径** | 选填 | 默认为 `/system/`。如果你在 AnqiCMS 中自定义了后台路径（如 `/admin888/`），请在此填写。 |
| **后台账号 / 后台密码** | 选填 | 用于后台跳转时的静默登录校验；密码输入框默认隐藏为 `•`，可点击右侧「显示」查看。 |

> **关于本地配置存储的说明**：
> 本工具为个人单机自用工具，`mcp_token` 与 `admin_password` 与原有的发布接口 Token 一致，保存在本地 `config.ini` 中（仅在填写非空值时写入），界面与运行日志中均会自动遮罩脱敏。请妥善保管本地 `config.ini` 文件。

配置完成后，可以直接点击面板右侧的：
- **「测试 MCP」**：即时探测当前站点的 MCP 接口连通性、服务端版本以及已开放的工具数量（无需先保存即可测试当前输入值）。
- **「跳转后台」**：立即在浏览器中打开该站后台。

---

### 1.2 在 AnqiCMS 网站后台获取 MCP Token 并开启接口权限

要使用 MCP 版本检测与在线升级等高级功能，请确认目标 AnqiCMS 站点（建议 v3.5.0 / v3.6.x 及以上版本）已完成以下设置：

1. **开启 API / 导入接口**：
   - 登录站点后台 → **「设置」→「安全设置」**（或「内容设置 / 接口设置」），确保 API 接口功能已开启。
2. **获取 MCP Token 并勾选「接口开放范围」**：
   - 进入站点后台 → **「设置」→「AI 统一配置」**（或 MCP 接口配置页）：
   - 开启 MCP 服务，生成或复制 **MCP Token**，粘贴到本工具对应站点的 `MCP Token` 输入框中。
   - 在**「接口开放范围」**中，按需勾选高危能力域：
     - 若需使用本工具的**「统一升级」**功能，必须勾选 **「系统升级」** 开放范围；
     - 若需使用 MCP 多站点/登录票据能力，请勾选 **「多站点」** 等对应范围。
   - 保存后台设置后，回到本工具点击**「测试 MCP」**，若提示 `MCP 可用` 且显示识别到升级/友链工具，即表示配置成功。

## 二、友情链接管理（友链中心）

点击主界面「管理」工具栏中的 **「友链中心」**（或在左侧站点列表右键点击 **「管理友链」**），打开友链中心窗口。窗口包含三个选项卡：

### 2.1 单站友链管理

用于查看、增删和检测单个站点的友情链接：

1. **查看与刷新**：在顶部下拉框选择目标站点，点击 **「刷新列表」**，表格将列出该站当前所有友链（ID、标题、网址、nofollow、状态、备注）。
2. **添加单条友链**：在下方表单填写「标题」、「网址」（必填，需以 `http://` 或 `https://` 开头），可选勾选 `nofollow`、填写「备注」与「对方反链页」，点击 **「添加友链」**。
   - 工具会自动拦截指向站点自身的链接（跳过自链）以及已存在的重复域名/路径链接。
3. **删除选中友链**：在表格中选中一条或多条友链，点击 **「删除选中」**。
4. **检测状态 / 反链检测**：点击 **「检测状态」** 可触发站点友链检测或本地并发访问对方页面（最多读取 512KB，不携带任何敏感 Token），检查对方页面是否可访问以及是否包含本站域名的反链。

---

### 2.2 统一上下链（多站批量添加 / 批量删除）

切换到 **「统一上下链」** 选项卡，可将一批外部或内部友链一次性添加到多个选中站点，或从多个站点批量撤下：

1. **选择目标站点**：在左侧站点选择器中，可通过**分组下拉框**、**搜索框**筛选站点，并点击复选框或「全选 / 反选」勾选目标站点。
2. **输入批量友链文本**：在右侧多行文本框中每行输入一条友链。支持以下全部常用格式（以 `#` 开头的注释行和空行会自动忽略，相同网址会自动去重）：

```text
# 格式 1：标题|网址|是否nofollow(可选)|备注(可选)
安企CMS官网|https://www.anqicms.com|0|官方友链
合作伙伴A|https://partner-a.example.com|nofollow|2026互换

# 格式 2：网址|标题
https://blog.example.com|技术博客

# 格式 3：标题 与 网址 用 Tab、英文逗号(,)、中文逗号(，) 或 空格 分隔
行业门户,https://portal.example.com
资讯中心 https://news.example.com

# 格式 4：纯网址（工具将自动提取域名作为友链标题）
https://tools.example.com
```

3. **解析预览**：点击 **「解析预览」**，工具会校验每一行格式并提示有效条数及具体错误行号（如 `第3行：网址无效`）。
4. **执行批量上链 / 批量下链**：
   - 点击 **「批量上链」**：并发向所有勾选站点添加这些友链（自动跳过自链与已存在友链）。
   - 点击 **「批量下链」**：从所有勾选站点中删除文本框内列出的网址对应的友链。
   - 执行过程中可随时点击 **「停止」** 取消后续未处理项；完成后可点击 **「导出 CSV」** 保存带 BOM 的 UTF-8 报表（Excel 可直接双击打开不乱码）。

---

### 2.3 站群互链（全互链 / 主从互链 / 轮链 & 台账回滚）

切换到 **「站群互链」** 选项卡，可在选中的多个自有站点之间按指定拓扑结构快速建立互链，并支持随时按台账安全回滚。

#### 第一步：选择互链模式与参数
在左侧勾选参与互链的站点（至少 2 个），选择以下三种模式之一：

| 互链模式 | 拓扑说明 | 生成友链总条数（设勾选 $n$ 个站点） |
| :--- | :--- | :--- |
| **两两全互链（Mesh）** | 任意两个站点之间互相添加对方为友链（A↔B, A↔C, B↔C…） | $n \times (n - 1)$ 条 |
| **主从互链（Hub-Spoke）** | 需在下拉框指定一个**「主站（Hub）」**：<br>• 不勾选双向：所有子站单向链接到主站（子站 → 主站）<br>• 勾选「双向互链」：子站与主站双向互加（子站 ↔ 主站） | 单向：$n - 1$ 条<br>双向：$2 \times (n - 1)$ 条 |
| **轮链（Ring）** | 按站点列表顺序首尾相连形成环路（站点 1 → 站点 2 → … → 站点 $n$ → 站点 1）：<br>• 勾选「双向互链」时同时建立反向环路 | 单向：$n$ 条<br>双向：$2n$ 条（2 站时自动去重为 2 条） |

- 友链锚文本自动使用目标站点的**「站点显示名」**（未设置则用「站点名称」），备注自动带上本次计划编号前缀（如 `站群互链#a1b2c3d4`）。

#### 第二步：先预览计划（Dry-run），再执行互链
为防止误操作，站群互链强制采用**「先预览、后执行」**机制：
1. 点击 **「预览计划 (Dry-run)」**：工具会并发读取各源站现有友链列表，在预览表格中清晰列出每一条计划项的状态（`待新建 planned`、`已存在跳过 skipped_exists` 或 `源站不可达 failed`）。
2. 核对无误后，「执行互链」按钮才会激活（若中途修改了勾选站点或模式，需重新预览）。
3. 点击 **「执行互链」** 并在确认弹窗中点击确定，工具将执行创建并将所有实际新建成功的友链写入本地台账（`设置/friendlink_ledger.json`）。

#### 第三步：历史台账回滚与解除互链
- **按计划精准回滚**：在下方「历史互链台账」列表中选中某次执行记录，点击 **「回滚所选计划」**。
  - **安全保证**：回滚**仅删除该次计划实际新建（`created`）的友链**，建链前站点原有的友链绝不会被误删。
- **解除所选站点间互链**：若想直接清理左侧勾选站点之间的所有互链（不论是否由台账创建），可点击 **「解除所选站点间互链」**。

## 三、一键直跳后台与多站批量打开

无论是日常巡检还是手工调整设置，你都可以通过以下任一入口快速打开站点后台：
- **主界面工具栏**：在左侧站点列表勾选一个或多个站点 → 点击「管理」栏的 **「跳转后台」**。
- **主界面右键菜单**：在左侧站点列表右键点击某站点 → 选择 **「跳转后台」** 或 **「复制后台地址」**。
- **配置中心 / 友链中心**：直接点击窗口内的 **「跳转后台」** 按钮。

### 三级自动降级机制
工具会按以下优先级自动尝试打开后台（任何一级未配置或失败都会平滑降级到下一级，确保 100% 能打开后台页面）：
1. **免密票据直跳（Tier 1）**：若站点 MCP 暴露了一次性登录票据工具，自动换取单次票据并通过本地 `127.0.0.1` 临时回环桥跳转进入后台。
2. **账号静默校验交接（Tier 2）**：若配置了后台账号与密码且配置了免密交接模板，先在后台校验凭据再通过本地回环桥交接。
3. **常规后台登录页直达（Tier 3）**：直接打开 `{站点网址}{后台路径}`（默认 `/system/`）。

### 多站批量打开保护
- 当一次勾选超过 **5 个** 站点时，工具会弹出确认提示，防止误触瞬间打开过多浏览器标签页。
- 单次批量打开最多处理前 **30 个** 站点，并在每个标签页之间自动间隔 400 毫秒。

## 四、统一检测版本与分批 / 金丝雀在线升级

点击主界面「管理」工具栏中的 **「统一升级」**（或在站点列表右键点击 **「检测版本」**），打开统一升级中心。

### 4.1 批量检测版本
1. 在左侧站点选择器勾选需要检查的站点（可按分组筛选）。
2. 点击 **「检测版本」**：工具会并发连接各站 MCP 接口，查询当前版本与最新可用版本，并在右侧表格展示：
   - **当前版本 / 最新版本 / 可升级状态**；
   - 若某站 Token 无效或未开启权限，对应行会高亮显示具体原因与修复提示（**双击任意结果行**可弹窗查看完整提示详情）。

### 4.2 金丝雀验证与分批在线升级
当检测到有新版本可升级时，推荐按以下安全流程执行批量升级：

1. **设置升级策略**（窗口中部控制栏）：
   - **并发数**：可设为 `1 ~ 5`（默认 `3`），控制同时执行升级的站点数量。
   - **☑ 先升级首个站点验证（金丝雀）**（强烈建议保持勾选）：工具会**先单独升级勾选列表中的第 1 个站点**，并等待其重启及验证版本号确实更新成功后，才开始按并发数升级其余站点。
   - **☑ 失败即停止后续**（强烈建议保持勾选）：若金丝雀首站或批次中出现升级失败，立即停止尚未开始的后续站点（标记为 `已跳过`），避免问题扩散到整个站群。
2. **启动升级**：
   - 点击 **「升级选中站点」**，在弹出的风险确认框中核对站点数量并确认。
   - 每个站点将依次经历：`连接中` → `检查版本` → `执行升级` → `等待重启` → `健康与版本校验` → `完成`。
   - **注意**：升级期间站点会自动重启，短时间连接断开属于正常现象，工具会自动轮询等待站点恢复并核实版本号是否提升。若升级正在进行中尝试关闭窗口，工具会弹窗二次确认。

## 五、常见问题排查（FAQ）

### 1. 提示「请登录该站后台：设置→AI 统一配置→接口开放范围，勾选对应高危域（系统升级/多站点）后重试」
- **原因**：站点 MCP 连接正常，但 AnqiCMS 默认处于安全保护状态，未向 MCP 开放「系统升级」等高危操作权限（状态显示为 `权限未开启 / scope_disabled` 或 `无升级工具 / no_tool`）。
- **解决**：登录该站后台 → **「设置」→「AI 统一配置」** → 在**「接口开放范围」**中勾选 **「系统升级」** 并保存，回到工具重新检测或升级即可。

### 2. 提示「MCP Token 无效或未开启」或「导入 Token 无效或未开启友情链接 API」
- **原因**：HTTP 返回 401/403，或者站点既没有填写 `MCP Token`，发布接口地址 `jiekou` 中也没有携带有效的 `?token=...`。
- **解决**：
  - 友链操作使用发布接口中的导入 Token，请核对「配置中心 → 发布接口地址」中的 `token=` 参数是否与后台「功能接口 / 内容导入接口」一致；
  - MCP 操作优先使用「配置中心 → 站群与后台 → MCP Token」，请核对后台「设置 → AI 统一配置」中的 Token 是否一致。

### 3. 提示「接口发生重定向，请把站点网址改为 https://...（或检查反代配置）」
- **原因**：为了防止您的敏感 Token 在 `http -> https` 或跨域名跳转过程中泄露，本工具对所有携带 Token 的请求均**严格禁止自动跟随 301/302 重定向**。当站点配置了强制 HTTPS 或 `www` 跳转，而工具里填写的仍是 `http://` 或未带 `www` 的旧地址时，就会收到此提示。
- **解决**：打开「配置中心」，将该站点的「站点网址」和「发布接口地址」直接修改为最终跳转后的实际地址（例如将 `http://` 改为 `https://`），保存后重试。

### 4. 提示「SSL 证书校验失败」
- **原因**：目标站点使用的是自签名证书、已过期证书，或反代服务器证书链不完整。
- **解决**：建议优先在服务器端修复或续期 SSL 证书；若属于内网测试环境确需跳过证书校验，可在 `设置/integration_settings.json` 中将 `"mcp": { "verify_ssl": false }` 设为 `false` 后重启工具。

### 5. 升级后提示「站点未在 N 秒内恢复（timeout）」或「升级后版本未变化」
- **原因**：
  - `timeout`：服务器下载升级包较慢，或进程守护（Supervisor / systemd / 宝塔守护进程）未能在升级退出后自动拉起 AnqiCMS 进程。
  - `升级后版本未变化`：升级工具返回成功，但站点目录无写入权限导致二进制文件未替换，或未触发重启。
- **解决**：先通过「跳转后台」检查站点是否已恢复；若无法访问，请登录服务器或宝塔面板检查 AnqiCMS 进程状态与目录读写权限。
